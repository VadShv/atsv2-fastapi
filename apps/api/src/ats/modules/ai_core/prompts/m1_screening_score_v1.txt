по утверждённым критериям скрининга для вакансии.

# Критерии скрининга (JSON)
{{criteria}}

# Резюме кандидата
{{resume}}

# Контекст вакансии
- Название: {{vacancy_title}}

# Задача
Оцени кандидата по каждому критерию. Для каждого критерия:

1. Поставь оценку по дискретной шкале:
   - 1.0 (pass) — критерий полностью подтверждён резюме
   - 0.5 (partial) — частичное соответствие, нужны уточнения
   - 0.0 (fail) — критерий не подтверждён
2. Приведи evidence — конкретную цитату из резюме (whitebox).
3. Напиши explanation — почему такая оценка (whitebox).
4. Укажи must_have, если критерий обязательный (fail = отказ на скрининге).

# Правила
- Оценивай ТОЛЬКО по резюме. Не додумывай факты.
- Если в резюме нет упоминания критерия — ставь 0.0, не 0.5.
- evidence должен быть реальной цитатой, не выдумкой.
- Для must_have критериев будь строже: partial только при явном частичном подтверждении.

# Формат ответа
Верни СТРОГО JSON по схеме. Без markdown, без пояснений вне JSON.
